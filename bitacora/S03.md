## Objetivo

Avanzar en el desarrollo técnico del dispositivo interactivo, integrar sus componentes electrónicos y construir prototipos estructurales para definir la disposición de los elementos del robot.

## Actividades realizadas en la sesión anterior

1. Se organizó el trabajo de desarrollo técnico entre programación y prototipado estructural.
2. Se comenzó a desarrollar el código de las distintas partes del dispositivo.
3. Se soldaron individualmente los pines de la pantalla de siete segmentos de dos dígitos a sus cables.
4. Se implementó el código para utilizar la pantalla y se identificó un problema en la representación de la información.
5. Se incorporó al código la configuración de un microservomotor para el movimiento del brazo.
6. Se realizaron prototipos de ensambles en cartón, con la intención de trasladar posteriormente la estructura a MDF mediante corte láser.
7. Se preparó en AutoCAD una plantilla de la estructura final para corte láser.

## Desarrollo electrónico

El código presentado en esta etapa incorpora:

- Sensor UV GUVA-S12SD conectado a la entrada analógica A0.
- Botón de activación.
- Buzzer para las alertas sonoras.
- LED RGB controlado mediante salidas PWM.
- Pantalla de siete segmentos de dos dígitos, gestionada mediante la biblioteca SevSeg.
- Microservomotor conectado al pin A4, configurado para mover el brazo.

En el código nuevo se establecen dos posiciones para el servomotor: una posición inicial de 0° y una posición elevada de 90°. La instrucción presentada activa la posición elevada cuando el índice UV es igual o superior a 8 y devuelve el brazo a la posición inicial en los demás casos.

La lógica de alertas también considera distintos rangos de índice UV para modificar el color del LED RGB y activar el buzzer.




El documento no especifica la causa del problema ni registra una solución definitiva, por lo que ambos puntos quedan pendientes de documentar.

## Desarrollo estructural

Se realizaron prototipos de ensambles en cartón para estudiar la estructura del dispositivo y preparar su posterior fabricación en MDF mediante corte láser.

También se elaboró en AutoCAD una plantilla de la estructura final destinada al corte láser.

## Resultados

- Se definió una distribución de responsabilidades entre programación y desarrollo estructural.
- Se avanzó en la integración de la pantalla de dos dígitos y en la programación de los componentes.
- Se incorporó al código la configuración de un servomotor para el movimiento del brazo del robot.
- Se realizaron ensambles de prueba en cartón.
- Se preparó una plantilla estructural en AutoCAD para corte láser.
- Quedó identificado un problema pendiente en la representación de la información en la pantalla (calibración del sensor).

## Decisiones y justificación

| Decisión | Evidencia o criterio | Consecuencia para el proyecto |
|---|---|---|
| Distribuir el trabajo entre programación y estructura | Se definió quién desarrollaría el código y quién trabajaría en los prototipos | Se organizaron las tareas técnicas del equipo |
| Incorporar un servomotor | El robot debe elevar uno de sus brazos como respuesta al nivel de radiación UV | Se agregó el control del microservo al código |
