## Desarrollo electrónico

El código presentado en esta etapa incorpora:

- Sensor UV GUVA-S12SD conectado a la entrada analógica A0.
- Botón de activación.
- Buzzer para las alertas sonoras.
- LED RGB controlado mediante salidas PWM.
- Pantalla de siete segmentos de dos dígitos, gestionada mediante la biblioteca SevSeg.
- Microservomotor conectado al pin A4, configurado para mover el brazo.

En el código nuevo se establecen dos posiciones para el servomotor: una posición inicial de 0° y una posición elevada de 90°. La instrucción presentada activa la posición elevada cuando el índice UV es igual o superior a 8 y devuelve el brazo a la posición inicial en los demás casos.

La lógica de alertas también considera distintos rangos de índice UV para modificar el color del LED RGB y activar el buzzer.
